# Creating Files and Folders
## 1. Touch 
- ***$ touch "filename"***: creates an empty file. commonly used before editing a new file.
- Provide a filename, and the file will be **created**(if it doesn't already exist.)
- Example: ***$ touch chicken.txt*** create chicken.txt in the current directory.
- If the file already exists, touch **does not overwrite** it. It simply update the access and modification dates to the current time.

## 2. File
- ***$ file "filename"*** Shows the *type* of file.
- Not very important, but sometimes useful!
- Example: ***$ file contract.pdf*** tells us the file type of contract.pdf <br>
*"contract.pdf: PDF document, version 1.4"*
- It does **NOT** use the file extension to determine the file type.
- We could have a pdf file named *app.png*

## 3. mkdir
- ***$ mkdir "foldername"*** Used to create new **directories** (folders)
- Stands for **"making directory"**
- Provide one or more directory names, and it will **create** them for you
- Example: to create two new folders, images and styles, we could run<br>
***$ mkdir image style***<br>

  ## Quick summary
  1. ***touch***: create a new empty file(or update timestamp if it exists).
  2. ***file***: determine the file type.
  3. ***mkdir***: create new directories(folders)
